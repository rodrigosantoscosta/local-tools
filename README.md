# local-tools

A collection of small tools that run locally in your browser, with no backend and no data sent to any server.

## Tools

| Tool | Description | Folder |
|------|-------------|--------|
| Paste Plain Text | Converts formatted text into plain text | [tools/paste-plain-text](tools/paste-plain-text) |

## Usage

1. Clone the repository:
   `git clone https://github.com/<username>/local-tools.git`
2. Open the `index.html` of the tool you want in your browser.

Or use it through GitHub Pages:
`https://<username>.github.io/local-tools/tools/<tool>/`
